# Google Advanced Data Analytics Certificate — Portfolio

This repository contains my projects from the Google Advanced Data Analytics Professional Certificate. Each folder corresponds to one course in the program and contains an end-of-course project applying that course's skills to a real-world-style dataset, following the **PACE** (Plan, Analyze, Construct, Execute) problem-solving framework.

## Projects

### [01 — Foundations of Data Science](./01-foundations-of-data-science)
**NYC Taxi Fare Data: Inspection & Cleaning Readiness Review**
Reviewed a 22,699-row NYC Yellow Taxi dataset to assess structure and quality ahead of building a fare-prediction model. Identified data quality issues (negative values, invalid codes, outliers) and recommended `trip_distance` and trip duration as the strongest fare predictors.
`pandas` · data cleaning · outlier detection · exploratory analysis
